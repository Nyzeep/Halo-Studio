# 将受管配置保持为用户本机私有数据

可复用配置档及工作区对配置档的选择只保存在本机 Halo Studio 用户数据中，不写入 Git 仓库、不随提交传播，也不在首次打开项目时自动生成仓库副本。Pi 的 `models.json`、`settings.json`、`auth.json` 和项目 `.pi` 配置只有在用户显式发起、查看 Diff、确认并可验证回滚的独立配置事务中才能被修改；P0 优先使用 Halo 非敏感配置与临时进程环境，从而避免凭据引用、模型偏好或本机运行策略污染项目历史。历史 OpenCode 配置材料不构成当前 P0 入口。
