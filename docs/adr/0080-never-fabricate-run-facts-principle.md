# 运行事实以「不虚构历史」为总原则并收口单一脱敏闸门

## ADR 关系

- 修订 ADR-0075：不改变其「Runtime 是事件事实唯一权威、交付证据是冻结派生快照」的结构；吸收决策票 #51 的四项原则为事实层总原则，双 Adapter（ADR-0078）使这些原则从 pi 单通道约束升级为执行器中立约束。
- 对 ADR-0042/0043/0048 的脱敏与诊断边界在双 Adapter 事件路径上统一强制，不放宽。

## 决策

（决策地图 #32；#51）

- **「不虚构历史」是事实层总原则**：事实层只记录执行器真实发生的事。失败尝试、重试与执行器交接各自记独立 attempt 事实，不合并、不回填成连续历史，也不进入模型可见历史的重建（与「任务中断」词条兼容）；取消如实落地为「已交付前缀 + `interrupted`」，不把取消改写为完成或失败；应用重启不自动恢复、不重放（继承 ADR-0075 的中断语义）。
- **事实只取 committed 粒度**：事件事实只接受执行器 committed 语义更新（durable 事件）；回复完成才落摘要事实。pi 的 token 级流式帧等活事件只进「活动会话记录」（UI 层），不进入事实日志与交付证据。事件域三分词汇（session 持久事实 / agent 活事件 / capability 策略挂载，对应 durable/live/policy 边界）进 P0，作为 Runtime 事件模型的校准器；只取语义分层，不跟随 DSH 持久化格式。
- **事实 kind 执行器中立**：保持三类核心 kind——用户消息摘要、Agent 回复摘要、工具活动——两 Adapter 规范化后落同一 `ManagedEventFactKind` 词汇；新增 kind 递增 schema_version。执行器差异进能力档案（ADR-0078），不进事实词汇。两执行器 `interrupted`/attempt 语义差异（DSH 原生 assistant/attempt 不虚构历史设计；pi 侧靠 abort/回收记录）在事实层如实表达，不做虚假对齐。
- **单一脱敏闸门**：Adapter 只做协议规范化；事实落盘前统一过 `normalize_summary`（脱敏/限长/fail-closed），规则一处生效、契约测试一处覆盖。两条事件路径（pi 与 DSH，含 `sdk` 金丝雀降级通道）都经同一闸门，降级时证据不断链。脱敏后的事实才可进入 Renderer、日志、持久化或交付证据（继承 ADR-0075/0042/0048）。

## 后果

- pi 单通道时代的「事件事实契约 + 内存 Adapter 先行」实施路径延续到双 Adapter：事实契约先于第二个 Adapter 落地，DSH 事件经规范化映射进同一词汇，而不是为 DSH 另立事实层。
- 「活动会话记录」成为 live 层的正式边界：UI 可以消费流式活事件，但任何持久化对象（事实日志、证据、快照恢复）只由 committed 事实派生；该边界同时是 ADR-0077 双 store 的分界依据。
- 契约测试对脱敏只需覆盖闸门一处；新增执行器事件面时先证明能映射到中立词汇与 committed 粒度，才允许接入。
