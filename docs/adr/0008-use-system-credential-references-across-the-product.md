# 全产品使用系统凭据库引用

Halo Studio 对 Pi RPC P0 和标准编码模式的模型统一使用操作系统凭据库保存密钥，持久化配置及其备份、IPC、日志和交付历史只保存凭据引用。Pi 的 `models.json`、环境变量和认证入口只能在受控子进程边界内解析；P0 不使用 `--api-key`，不把 Pi `auth.json` 当作 Halo 凭据库，也不允许明文回退。历史 OpenCode 适配器不构成 Halo P0 凭据入口。系统凭据库不可用时相关操作失败关闭。该决定统一了产品安全边界，并要求后续维护承担凭据迁移与脱敏验证。
