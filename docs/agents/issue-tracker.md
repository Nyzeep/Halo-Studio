# Issue tracker: GitHub

Halo Studio 的需求规格、开发任务和缺陷均使用 GitHub Issues 管理，对应远端为 `Nyzeep/Halo-Studio`。

## Conventions

- 创建、阅读、评论、关闭和标记 Issue 时使用 `gh` CLI，并在仓库工作目录中执行。
- 完整需求规格以一个 GitHub Issue 发布；实现任务以独立 Issue 发布，并明确其阻塞关系。
- 可由 agent 执行的已充分规格化任务使用 `ready-for-agent` 标签。
- Pull Request 不是需求分诊入口；外部 PR 不进入 triage 队列。

## When a skill says "publish to the issue tracker"

Create a GitHub issue in this repository.
