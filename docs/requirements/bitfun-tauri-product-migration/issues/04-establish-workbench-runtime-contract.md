# 04 - 建立 Halo Workbench Runtime 公共契约

**What to build:** Halo 工作台可以通过一组小而稳定的 Tauri command/event 契约读取运行时状态、当前工作区与结构化事件，并在界面中展示真实连接结果，而不直接依赖旧 Sidecar 或分散的底层命令。

**Blocked by:** 03 - 启动 Halo 品牌的 Tauri 开发工作台.

**Status:** ready-for-agent

- [ ] 公共契约覆盖运行时状态、工作区快照、会话入口和有序结构化事件，并具有明确的错误与版本语义。
- [ ] 前端只通过该公共契约访问 Halo 管理的运行事实，不直连旧 Sidecar 或多个并行权威状态源。
- [ ] 用户可以从工作台看到真实的未连接、就绪和失败状态及可操作原因。
- [ ] 契约测试从 Tauri 边界验证用户可观察结果，不锁定私有 Rust 函数或 React 组件状态。
- [ ] 关闭或重启桌面应用会有序释放模块资源，不留下第二套常驻运行时。
