# 08 - 完成首轮受管任务会话

**What to build:** 本地开发者可以在受信任 Git 工作区显式创建受管任务、选择主执行器并发送首轮消息；真实执行器回复后任务进入“等待开发者”，同时记录任务基线和脱敏运行轨迹。

**Blocked by:** 07 - 在 Tauri 运行时探测并启动 OpenCode 1.x.

**Status:** ready-for-agent

- [ ] 受管交付模式必须由用户显式选择，并要求用户确认受信任 Git 工作区。
- [ ] 创建任务时记录 Git 基线，区分已有改动和任务期间改动，不要求工作树预先干净。
- [ ] 用户可以选择 Code Agent、Pi 或 OpenCode 作为主执行器并发送首轮任务消息。
- [ ] 首轮回复后任务进入等待开发者而非自动完成，界面展示脱敏、限长的消息与结构化运行轨迹。
- [ ] 契约测试使用真实运行时边界或受控替身覆盖创建、首轮、等待状态、错误和凭据不泄漏。
