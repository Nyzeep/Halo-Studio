# 10 - 追问、显式结束并审查交付

**What to build:** 本地开发者可以在同一受管任务会话继续追问，让执行器产生真实工作区改动，随后显式结束会话并在只读交付审查中接受或拒绝结果，而 Halo 不会代替用户执行 Git 交付操作。

**Blocked by:** 09 - 处理一次性 Agent 操作请求.

**Status:** ready-for-agent

- [ ] 等待开发者状态允许在同一任务和原生会话中追问，运行中不可并发重复提交。
- [ ] 执行器按原生权限模型直接产生工作区改动，Halo 记录基线后的归因并保留用户已有改动。
- [ ] 只有用户显式结束会话后才固定 Diff、摘要、验证结果和运行结论并进入可审查交付。
- [ ] 只读审查展示变更、归因、验证结果与证据新鲜度；后续文件变化会使相关证据过期。
- [ ] 接受或拒绝只记录交付结论，不自动提交、暂存、推送、回滚、删文件或改写 Git 历史。
