# 09 - 处理一次性 Agent 操作请求

**What to build:** 当受管执行器需要权限、澄清或高风险外部操作时，本地开发者可以在原生 UI 对准确的当前请求作出一次性决定，运行时只在原生执行器确认后继续。

**Blocked by:** 08 - 完成首轮受管任务会话.

**Status:** ready-for-agent

- [ ] 权限请求只能本次允许或拒绝，不创建会话级、跨任务或永久授权。
- [ ] 澄清请求只能回答或拒绝，并与当前原生请求精确对应。
- [ ] 浏览器或 Computer Use 对工作区外产生写入影响时必须进入高风险外部操作请求。
- [ ] 请求在决定提交期间不可重复响应，并只在原生执行器确认后从界面消失。
- [ ] 自动化覆盖允许、拒绝、过期、重复响应、执行器失败和应用重启后的不重放语义。
