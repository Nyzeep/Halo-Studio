# 11 - 保持中断如实化与不重放语义

**What to build:** Halo 工作台或受管运行时意外退出后，未结束任务会如实显示为中断；重启不会自动重连、重发消息、重放操作请求或重复执行文件写入。

**Blocked by:** 10 - 追问、显式结束并审查交付.

**Status:** ready-for-agent

- [ ] 应用关闭、运行时崩溃和进程失联都会把非终态受管任务归类为中断而非完成。
- [ ] 重启后不自动恢复原生会话，不重发首轮或追问，也不重放一次性决定。
- [ ] 已产生的工作区改动和可审查证据按事实保留，活动消息与敏感运行态按隐私边界清理。
- [ ] 用户可以从原生 UI 看见中断原因和后续可选处置，系统不暗示任务已成功。
- [ ] 集成测试覆盖关键状态点的中断、无重放、Git 不变性和凭据不泄漏。
