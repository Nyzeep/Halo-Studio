# 12 - 证明旧六票的行为等价迁移

**What to build:** 发布负责人可以通过一份逐项矩阵确认旧产品基座上的可迁移能力已在 Halo Tauri 产品中获得等价的用户可观察行为证据，且没有把旧内部协议当作兼容目标。

**Blocked by:** 11 - 保持中断如实化与不重放语义.

**Status:** ready-for-agent

- [ ] 矩阵逐项映射旧六票的用户行为、旧证据、新 Tauri 契约证据、新桌面路径和当前结论。
- [ ] 工作区、配置与凭据、运行时兼容、首轮会话、一次性请求、追问、显式结束、审查和中断均有新产品证据。
- [ ] Rust 契约、前端测试、桌面烟测和必要端到端测试从 Halo 正式入口执行并通过。
- [ ] 旧 Sidecar JSONL 封包、Python/QML 适配器和私有实现布局不得成为等价断言。
- [ ] 缺失、失败或尚未人工执行的项目明确标为阻断，不得推断或伪造通过。
