# 07 - 在 Tauri 运行时探测并启动 OpenCode 1.x（历史）

**What to build:** 本地开发者可以从 Halo 工作台检查本机 OpenCode 1.x 的兼容性并启动真实运行时；版本、能力、认证或健康检查失败都会如实显示，且不会退回模拟协议。

**Blocked by:** 05 - 打开工作区并运行标准编码会话; 06 - 管理运行时配置与系统凭据.

**Status:** ready-for-agent

- [ ] OpenCode 1.x 按兼容性档案检查版本与必需能力，未知主版本不会仅因版本较新而放行。
- [ ] 真实启动使用受管配置、回环连接、每次启动的认证材料和原生健康检查。
- [ ] ready、failed 与恢复建议通过 Workbench Runtime 公共契约进入原生 UI。
- [ ] 不保留旧 JSONL 假设协议或模拟任务流作为生产回退。
- [ ] 测试覆盖兼容通过、不支持版本、能力缺失、凭据缺失、认证失败、健康失败和敏感信息脱敏。
