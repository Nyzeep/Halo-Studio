# 06 - 管理运行时配置与系统凭据

**What to build:** 本地开发者可以在 Halo 工作台配置 Code Agent、Pi 与 OpenCode 的模型和启动选项，将密钥安全写入系统凭据存储，并让标准模式与受管模式共享同一份受管配置。

**Blocked by:** 04 - 建立 Halo Workbench Runtime 公共契约.

**Status:** ready-for-agent

- [ ] 配置界面和公共契约只持久化模型、启动选项与凭据引用，不持久化凭据明文。
- [ ] 凭据录入只在隔离流程中写入系统凭据存储；存储不可用或引用缺失时失败关闭。
- [ ] 前端状态、事件、日志、备份、错误和交付历史不会包含密钥、Authorization 或可还原的认证信息。
- [ ] 标准编码模式与受管交付模式读取同一个配置权威源，不形成两套相互漂移的设置。
- [ ] 自动化覆盖录入、更新、删除、缺失引用、存储失败和统一脱敏边界。
