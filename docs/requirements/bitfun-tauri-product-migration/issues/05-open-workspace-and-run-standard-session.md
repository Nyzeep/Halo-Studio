# 05 - 打开工作区并运行标准编码会话

**What to build:** 本地开发者可以在 Halo 工作台打开 Git 工作区，使用 BitFun 原生标准编码会话与工具，并保留可重开的会话历史；这些会话不会被误记为受管交付。

**Blocked by:** 04 - 建立 Halo Workbench Runtime 公共契约.

**Status:** ready-for-agent

- [ ] 用户可以选择、打开和切换本地 Git 工作区，并看见路径、分支与工作树状态。
- [ ] 标准编码模式沿用 BitFun 原生会话、工具和历史重开能力。
- [ ] 标准会话不生成 Halo 受管任务状态、交付证据或接受结论。
- [ ] 标准模式保留 BitFun 原生 Git 能力，不因受管交付策略被全局禁用。
- [ ] Tauri 契约与桌面测试覆盖打开工作区、发送消息、接收事件和重新打开标准会话。
