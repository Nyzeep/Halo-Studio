**Blocked by:** 12 - 证明旧六票的行为等价迁移; 13 - 演练 BitFun 上游同步与许可证门槛.

**Status:** ready-for-agent

- [ ] 从正式 Halo Tauri 入口完成兼容启动、首轮消息、一次性请求、追问和一项无害工作区改动。

- [ ] 验收记录仅包含版本、兼容性档案和脱敏结论，不记录密钥、完整对话、端口、Authorization 或 session/message 标识。
