# 03 - 一次性 Agent 操作请求

**What to build:** 当真实 OpenCode 在受管任务会话中请求权限或澄清时，本地开发者可以在活动会话记录内仅本次允许、拒绝或回答；Agent 收到明确决定后继续、失败或保持可取消状态。

**Blocked by:** 02 - 首次受管任务会话与等待开发者.

**Status:** ready-for-agent

- [ ] 权限和澄清请求以会话内卡片呈现，包含用户可理解的请求内容和当前任务关联。
- [ ] 权限仅支持本次允许或拒绝；澄清仅支持回答或拒绝；任何路径都不写入永久放行规则。
- [ ] 任务在等待决议时如实进入操作请求状态，决议后按 Agent 的真实反馈回到运行、等待开发者或失败。
- [ ] 不匹配的请求、重复决议、拒绝和取消均有稳定错误处理，不会错误地批准其他请求。
- [ ] 自动化测试覆盖真实协议测试替身的权限和澄清回路，以及界面中各决定的可见状态。
