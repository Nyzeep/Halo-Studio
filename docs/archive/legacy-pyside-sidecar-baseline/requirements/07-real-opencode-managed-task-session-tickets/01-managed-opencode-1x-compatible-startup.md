# 01 - 受管 OpenCode 1.x 兼容启动

**What to build:** 本地开发者可以在现有原生界面中为 OpenCode 选择受管启动配置、检查兼容性并启动真实运行时；兼容、凭据或启动失败都以诚实状态、中文原因和恢复建议呈现。

**Blocked by:** None - can start immediately.

**Status:** ready-for-agent

- [ ] 启动配置只接收可执行程序、模型和凭据引用，密钥不出现在界面、IPC、日志、数据库或错误中。
- [ ] OpenCode 从 1.18.5 起的 1.x 更新可按兼容性档案通过启动检查；未知主版本或缺失能力必须失败关闭，而不是按“版本较新”放行。
- [ ] 真实 OpenCode 启动使用回环服务、每次启动的新认证和真实健康检查，不保留旧的假设任务协议作为生产回退。
- [ ] 用户能在现有运行时状态表面看见 ready、failed 和对应恢复建议，且 Pi 的不可用状态不被伪造成在线。
- [ ] 自动化测试覆盖兼容通过、版本家族不支持、凭据缺失、认证失败、健康失败和认证信息不泄漏。
