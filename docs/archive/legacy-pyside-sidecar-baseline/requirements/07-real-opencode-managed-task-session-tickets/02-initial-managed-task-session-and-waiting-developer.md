# 02 - 首次受管任务会话与等待开发者

**What to build:** 本地开发者创建 Agent 任务并发送第一条任务消息后，Halo Studio 通过已启动的真实 OpenCode 建立受管任务会话，展示整理后的真实回复和运行轨迹；Agent 一轮回复后，任务进入“等待开发者”而非自动审查或结束。

**Blocked by:** 01 - 受管 OpenCode 1.x 兼容启动.

**Status:** ready-for-agent

- [ ] 任务仍是唯一会话容器，首条任务说明成为首条用户消息，不新增自由聊天入口。
- [ ] Sidecar 使用 OpenCode 的真实会话、消息和事件能力完成首轮交流，并将端口、认证信息和远程会话标识保持私有。
- [ ] 任务界面显示活动会话记录中的用户消息和经脱敏、限长处理的 Agent 回复；原始工具日志不进入该区域。
- [ ] 一轮回复后的可见状态为“等待开发者”，在开发者明确结束前不生成交付证据或进入审查。
- [ ] 任务快照能重建活动会话记录；会话文本不写入交付历史。
- [ ] 自动化测试覆盖初次消息、真实协议测试替身、消息截断脱敏、事件乱序和等待开发者状态迁移。
