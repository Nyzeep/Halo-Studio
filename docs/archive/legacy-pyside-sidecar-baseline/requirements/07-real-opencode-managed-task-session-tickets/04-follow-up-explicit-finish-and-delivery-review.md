# 04 - 追问、显式结束与交付审查

**What to build:** 本地开发者可以在“等待开发者”状态中向同一受管任务会话发送追问；当开发者显式结束会话时，Halo Studio 固定真实工作区变更并进入既有只读交付审查。

**Blocked by:** 02 - 首次受管任务会话与等待开发者; 03 - 一次性 Agent 操作请求.

**Status:** ready-for-agent

- [ ] 只有等待开发者的活动任务可以发送后续消息；用户能看到追问及对应的整理后回复。
- [ ] 开发者能明确结束会话；运行中的 Agent 不会被误当作正常结束，取消路径仍保持独立。
- [ ] 显式结束后沿用任务基线生成关联 Diff、证据摘要和验证结论，并转入只读审查。
- [ ] 接受或拒绝交付仍不执行 Git 提交、推送、分支、回滚或删除。
- [ ] 活动会话记录不会作为完整对话写入审查包、历史或证据数据库。
- [ ] 自动化与真实验收工作区共同证明：无害文件改动、一次追问、显式结束和 Diff 审查构成一条完整路径。
