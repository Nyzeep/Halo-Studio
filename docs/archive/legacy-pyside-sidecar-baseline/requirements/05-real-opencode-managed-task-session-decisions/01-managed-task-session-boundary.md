# 01 - 定义受管任务会话边界

**类型：** grilling  
**状态：** resolved  
**Blocked by：** None

## Question

“进入对话并完成简单任务”是否意味着 Halo Studio 要提供无限制自由聊天，还是应保持现有 Agent 任务和可审查交付边界？

## Answer

采用受管任务会话：它围绕一个明确创建的 Agent 任务，允许初始消息和同一任务内的后续追问或澄清，但不是通用聊天。

Agent 一轮回复后进入“等待开发者”，而不是自动完成。开发者可以继续发消息；只有开发者显式结束会话后，才固定交付证据并进入审查。

## Consequences

- 外部 IPC 保持任务命名空间，不新增通用聊天 API。
- 任务状态机需要表达“等待开发者”。
- 完整会话不进入交付历史；只保留脱敏后的摘要与证据。
