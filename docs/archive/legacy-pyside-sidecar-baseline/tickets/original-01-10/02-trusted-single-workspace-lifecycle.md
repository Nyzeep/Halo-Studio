# 02 - 可信单工作区生命周期

**构建目标：** 让本地开发者显式打开一个经真实路径校验的 Git 工作区、确认其信任状态，并在切换工作区、撤销信任或退出时停止并清理旧工作区的受管运行时。

**依赖：** 01 - 原生工作台最小闭环。

**状态：** 已验收（自动化通过）。

- [x] 未信任工作区不能加载项目 Agent 配置、插件或启动运行时。
- [x] 同一时刻只有一个活动工作区，切换时不会遗留旧工作区进程。
- [x] 空格和 CJK 路径、目录替换和不可读目录均得到明确的用户可见结果。
- [x] 工作区状态通过 Sidecar 契约提供，且有集成测试覆盖生命周期边界。

**验收与 TDD 证据：** `docs/requirements-alignment/03-original-ten-task-acceptance-and-tdd-baseline.md`、`docs/traceability.md`。
