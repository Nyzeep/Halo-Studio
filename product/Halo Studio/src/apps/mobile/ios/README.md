# Halo Studio iOS

iOS application entrypoint.

Provisional source layout:

- `Halo Studio/App/`: application lifecycle and composition root.
- `Halo Studio/Features/`: iOS product features and native UI.
- `Halo Studio/Infrastructure/`: iOS adapters and platform services.
- `Halo Studio/Resources/`: assets and localized resources.

Add the Xcode project after the UI stack, bundle identifier, deployment target,
and shared-core integration strategy are selected.
